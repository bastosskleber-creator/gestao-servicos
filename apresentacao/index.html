Para quem é o Áster Conecta?

Para consultores e instrutores que querem organizar trabalhos, agenda, deslocamentos, hospedagens, despesas e recebimentos. O piloto foi pensado para testar essa rotina com os próprios profissionais.

Preciso fazer uma simulação para agendar?

Não. Você pode cadastrar um serviço diretamente em Serviços ou usar Agendar serviço na Agenda. A simulação é uma opção para avaliar a viabilidade antes de assumir o compromisso. Se a data ainda depende de confirmação, use a pré-reserva.

Meus dados ficam na nuvem?

Nesta versão piloto, os registros ficam no navegador e dispositivo usados para acessar o sistema. A cópia interna também fica nesse navegador. A cópia em uma pasta do Google Drive depende do Drive para computador configurado e da permissão para gravar nessa pasta. Backup não é sincronização automática dos registros entre aparelhos.

Posso consultar a agenda no celular?

O sistema possui integração com o Google Agenda, mediante conexão e autorização. Depois de sincronizar, os compromissos enviados podem ser consultados no aplicativo do calendário. Isso não transfere automaticamente todo o banco de dados do sistema para o celular. Confira o estado da sincronização antes de confirmar uma nova data.

Como proteger os meus registros?

No módulo Backup e dados, mantenha a cópia interna automática e faça também um backup manual ou em uma pasta externa autorizada. Antes de limpar dados do navegador, mudar de computador ou atualizar uma versão local do HTML, confira se você tem uma cópia externa recente.

Onde encontro ajuda para usar a ferramenta?

No menu Guia de uso, dentro do sistema. Há instruções por assunto, busca por palavras e opção para imprimir ou salvar o guia em PDF. Se encontrar uma dificuldade, compartilhe o relato com quem convidou você para o piloto.
